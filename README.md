# 作业清单网站 — 数据格式与人工维护手册

这个仓库是你的「每晚作业清单」网站（GitHub Pages 托管，网址 https://sb-bey.github.io/homework-list/ ）。

网页本身（index.html）**不存任何作业数据**，它每天自动去 `data/latest.json` 这个文件里"读"当天作业。所以维护网站 = **维护 JSON 数据文件**。

下面用最啰嗦的方式，一步一步教你：JSON 文件放哪、叫什么名、里面每个字是什么意思、怎么从零写一个、怎么改、怎么检查有没有写错。

---

## 一、先看懂仓库里都有什么

```
homework-list/
├── index.html            ← 网页模板（不要动它，除非改样式/功能）
├── README.md             ← 本手册
├── favicon.png           ← 网站小图标（不用管）
├── data/                 ← ★ 作业数据都放这里 ★
│   ├── latest.json       ← "当天"数据：网页每天就读它（每晚更新成最新一天）
│   ├── 2026-10-03.json   ← 历史存档：每天一个文件，只增不改
│   └── 2026-10-07.json   ← （举例）以后每天新建一个这种文件
├── photos/               ← 作业照片都放这里
│   └── 2026-10-03.jpg    ← 每天一张，文件名按日期
```

**核心规则（记住这 4 条）**
1. 每天新建一个 `data/2026-10-XX.json` 存当天的作业（历史文件**永远不覆盖**）。
2. 再把当天内容**复制**到 `data/latest.json`（网页读这个）。
3. 照片压缩后存成 `photos/2026-10-XX.jpg`，在 json 里填上文件名。
4. 勾选进度"按天分开"靠 json 里的 `key` 字段（每天换一个新 key，见下文）。

## 二、JSON 文件长什么样（逐行翻译）

以 `data/2026-10-03.json` 为例：

```json
{
  "date": "2026-10-03",
  "label": "10月3日 周六 · 国庆假期",
  "key": "hw-list-2026-10-03",
  "photo": "photos/2026-10-03.jpg",
  "items": [
    { "text": "试卷×2", "subject": "化学", "done": false },
    { "text": "《基》写到12页", "subject": "语文", "done": false }
  ]
}
```

每个字段的意思（务必逐条看清）：

| 字段 | 填什么 | 例子 | 注意 |
|---|---|---|---|
| `date` | 当天日期，格式必须是 **年-月-日**，数字别补多余的东西 | `"2026-10-07"` | 和文件名里的日期一致 |
| `label` | 网页标题旁边显示的那行字，怎么写都行，自己看得懂就好 | `"10月7日 周三"` | 建议带上星期几 |
| `key` | 网页在手机里"记勾选进度"用的钥匙，**每天必须换新的**，格式 `hw-list-年-月-日` | `"hw-list-2026-10-07"` | 如果两天用同一个 key，勾选会互相串！ |
| `photo` | 作业原图路径；**今天没照片就写成空字符串** | 有图：`"photos/2026-10-07.jpg"`；无图：`""` | 看图：`photos/` + 文件名 |
| `items` | 作业列表，一对方括号 `[ ]`，里面每项作业用花括号 `{ }` 包起来，**逗号隔开** | 见下 | 没作业就写 `[]`（空列表） |

### items 里"每一项作业"怎么写

每一项作业都是这样一个小块，**必须有 3 个字段，顺序无所谓，但名字一个都不能拼错**：

```json
{ "text": "试卷×1", "subject": "数学", "done": false }
```

| 字段 | 填什么 | 例子 | 注意 |
|---|---|---|---|
| `text` | 作业内容，写人话 | `"试卷×1"`、`"《基》写到12页"` | 文字两边要有英文引号 `"` |
| `subject` | 科目，**只能填这 7 个字之一**：`语文` `数学` `英语` `历史` `政治` `化学` `物理` | `"数学"` | 填别的字（比如"物理作业"）网页分组会乱 |
| `done` | 这个作业做完了没，只能填 `true`（做完了）或 `false`（没做完） | `false` | 每天新文件里都写 `false`，让用户自己勾 |

**注意：**
- 有两项作业 → 两项之间用英文逗号 `,` 隔开。
- 最后一项后面**不要**加逗号（加了你就会看到网页读不出来）。
- `true` / `false` 是小写，**没有引号**；`text` / `subject` 的值要加引号。别搞反了。

## 三、从零手写一个当天文件（一步步抄）

假设今天是 2026-10-07（周三），作业有：语文《基》P12、数学试卷1张、英语背诵。

### 第 1 步：新建文件
在 `data/` 文件夹里新建一个文件，名字叫：`2026-10-07.json`

### 第 2 步：把下面的内容抄进去，按你的作业改

```json
{
  "date": "2026-10-07",
  "label": "10月7日 周三",
  "key": "hw-list-2026-10-07",
  "photo": "",
  "items": [
    { "text": "《基》写到12页", "subject": "语文", "done": false },
    { "text": "试卷×1", "subject": "数学", "done": false },
    { "text": "背诵", "subject": "英语", "done": false }
  ]
}
```

### 第 3 步：改哪里
- `date` / `label` / `key` 里的日期改成当天。
- `photo` 有照片就填路径，没有就保持 `""`。
- `items` 里按上面"每一项"的格式，想加几项加几项。

### 第 4 步：复制一份到 latest.json
把 `2026-10-07.json` 的**全部内容**（一字不差）复制，粘贴覆盖进 `data/latest.json`。网页读的就是它。

> 偷懒办法：直接复制 `2026-10-07.json` 文件，重命名为 `latest.json`，覆盖旧的就行。

### 第 5 步：提交上传
把整个 `data/` 文件夹一起提交（git add → commit → push，或用 GitHub 网页直接上传）。1-2 分钟后网页自动变成当天的清单。

## 四、照片怎么放

1. 把当天作业照片压缩一下（手机拍的 2-5MB 太大，网页打开会卡；压到宽 1200px、质量 80 左右，几十 KB 最舒服）。
2. 存进 `photos/` 文件夹，文件名用日期：`2026-10-07.jpg`。
3. 在 json 的 `photo` 字段填 `"photos/2026-10-07.jpg"`。
4. 网页顶部就会出现「📷 作业原图」，点开看大图。

没照片：`photo` 填 `""`，网页自动不显示照片那块。

## 五、常见错误自查表（写错最常犯的 5 个）

| 症状 | 原因 | 怎么改 |
|---|---|---|
| 网页显示"拉不到作业数据" | JSON 写坏了（最常见的：多逗号、少逗号、用了中文引号 `“”` 而不是英文 `""`） | 用校验工具检查，见下 |
| 网页里作业乱分组 / 没科目 | `subject` 填了 7 个字以外的内容（如"物理作业"） | 改成 `物理` 等标准科目名 |
| 勾选进度和昨天串了 | `key` 没换新 | 改成 `hw-list-2026-10-07` 这种当天日期 |
| 某一天作业凭空多出来 / 少了 | `latest.json` 忘更新，网页还读着旧一天 | 重新覆盖 `latest.json` |
| 作业照片不显示 | `photo` 路径填错，或照片没传上去 | 核对 `photos/` 里文件名和路径一字不差 |

### 怎么确认 JSON 没写坏（必做）
写完任何一个 json，**先校验再提交**，两种办法任选：
- 电脑上：把内容贴进 https://jsonlint.com 之类网站，点 Validate，显示绿色对勾就没问题。
- 命令行：`python3 -m json.tool 你的文件.json`，不报错就是好的。

## 六、每晚固定流程（照做就行）

1. 用户发作业照片/文字 → 按上面第三节新建 `data/2026-10-XX.json`。
2. 照片处理 → 按第四节放好并填 `photo`。
3. 覆盖 `data/latest.json` 为当天内容。
4. 校验 JSON 无误 → git 提交推送 → 1-2 分钟后网站自动更新。

**铁律：**
- 历史 json（如 `2026-10-03.json`）**绝不修改、绝不删除**。
- 只新建、只更新 `latest.json`。
- `key` 每天换新，`done` 全填 `false`。
